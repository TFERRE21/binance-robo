Passo a passo

  1. Entre na sua conta Binance.
  2. Acesse Perfil → Conta → Gerenciamento de API.
  3. Clique em Criar API e conclua as verificações de segurança.
  4. Copie a API Key e o API Secret para o formulário do CriptoPro.
  5. Deixe saque/desembolso desativado. Ative somente as permissões necessárias para negociação.
⚠️ Nunca envie sua API Key ou API Secret para outra pessoa. O CriptoPro não precisa de permissão de saque para acompanhar e operar a conta.
